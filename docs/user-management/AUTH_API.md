# Auth Service API Reference\n\n## Base URL\n\n```\nGET/POST/PUT https://localhost:8443/api/auth\n```\n\nAll requests use HTTPS. JWT tokens required for protected endpoints.\n\n## Endpoint Reference\n\n### POST /register\n\n**Register a new user account**\n\nRequest:\n```json\n{\n  \"name\": \"John Doe\",\n  \"email\": \"john@example.com\",\n  \"password\": \"securePassword123\"\n}\n```\n\nValidation:\n- `name`: 2-255 characters, non-empty\n- `email`: valid email format, unique in system\n- `password`: minimum 6 characters\n\nResponse (201 Created):\n```json\n{\n  \"token\": \"eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...\",\n  \"user\": {\n    \"id\": 1,\n    \"email\": \"john@example.com\",\n    \"name\": \"John Doe\"\n  }\n}\n```\n\nErrors:\n- `400 Bad Request` - missing/invalid fields\n- `409 Conflict` - email already exists\n- `500 Internal Server Error` - database error\n\n### POST /login\n\n**Authenticate user and receive JWT token**\n\nRequest:\n```json\n{\n  \"email\": \"john@example.com\",\n  \"password\": \"securePassword123\"\n}\n```\n\nResponse (200 OK):\n```json\n{\n  \"token\": \"eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...\",\n  \"user\": {\n    \"id\": 1,\n    \"email\": \"john@example.com\",\n    \"name\": \"John Doe\"\n  }\n}\n```\n\nWith 2FA active:\n```json\n{\n  \"requires2FA\": true,\n  \"tempToken\": \"eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...\"\n}\n```\n(tempToken valid for 5 minutes)\n\nErrors:\n- `401 Unauthorized` - invalid credentials\n- `404 Not Found` - user not found\n\n### POST /2fa/setup\n\n**Initiate 2FA setup and get QR code**\n\nRequest Auth:\n```\nAuthorization: Bearer <jwt_token>\nContent-Type: application/json\n```\n\nRequest body: None (empty)\n\nResponse (200 OK):\n```json\n{\n  \"secret\": \"JBSWY3DPEBLW64TMMQ======\",\n  \"qrCode\": \"data:image/png;base64,iVBORw0KGgoAAAANSUhEUgAA...\",\n  \"manualEntryKey\": \"JBSWY3DPEBLW64TMMQ\"\n}\n```\n\nUser should:\n1. Scan QR code with authenticator app (Google Authenticator, Authy, etc.)\n2. Or manually enter `manualEntryKey`\n3. Test a 6-digit code via `POST /2fa/verify`\n\nErrors:\n- `401 Unauthorized` - no token\n- `400 Bad Request` - already has 2FA enabled\n\n### POST /2fa/verify\n\n**Enable 2FA after user confirms code**\n\nRequest Auth:\n```\nAuthorization: Bearer <jwt_token>\nContent-Type: application/json\n```\n\nRequest body:\n```json\n{\n  \"token\": \"123456\"\n}\n```\n\nResponse (200 OK):\n```json\n{\n  \"message\": \"2FA enabled successfully\",\n  \"backup_codes\": [\n    \"XXXX-XXXX-XXXX\",\n    \"XXXX-XXXX-XXXX\"\n  ]\n}\n```\n\nValidation:\n- `token`: 6-digit TOTP code (within 30s window)\n- Time-based: server checks TOTP against synchronized clock\n\nErrors:\n- `401 Unauthorized` - no token\n- `400 Bad Request` - invalid TOTP code\n- `409 Conflict` - 2FA already enabled for user\n\n### POST /2fa/disable\n\n**Disable 2FA (requires current 2FA code)**\n\nRequest Auth:\n```\nAuthorization: Bearer <jwt_token>\nContent-Type: application/json\n```\n\nRequest body:\n```json\n{\n  \"token\": \"123456\"\n}\n```\n\nResponse (200 OK):\n```json\n{\n  \"message\": \"2FA disabled successfully\"\n}\n```\n\nValidation:\n- `token`: must be valid 6-digit code from authenticator app\n- Proves user owns the device/key before disabling\n\nErrors:\n- `401 Unauthorized` - no token\n- `400 Bad Request` - invalid TOTP code\n- `409 Conflict` - 2FA not enabled\n\n### POST /2fa/authenticate\n\n**Complete 2FA login flow (after receiving tempToken)**\n\nRequest Auth: None (use tempToken)\n```\nContent-Type: application/json\n```\n\nRequest body:\n```json\n{\n  \"tempToken\": \"eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...\",\n  \"token\": \"123456\"\n}\n```\n\nResponse (200 OK):\n```json\n{\n  \"token\": \"eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...\",\n  \"user\": {\n    \"id\": 1,\n    \"email\": \"john@example.com\",\n    \"name\": \"John Doe\"\n  }\n}\n```\n\nErrors:\n- `401 Unauthorized` - invalid tempToken or expired (>5 min)\n- `400 Bad Request` - invalid TOTP code\n\n### GET /2fa/status\n\n**Check if user has 2FA enabled**\n\nRequest Auth:\n```\nAuthorization: Bearer <jwt_token>\n```\n\nResponse (200 OK):\n```json\n{\n  \"enabled\": true,\n  \"setup_at\": \"2026-03-16T10:30:00Z\"\n}\n```\n\nOr:\n```json\n{\n  \"enabled\": false\n}\n```\n\nErrors:\n- `401 Unauthorized` - no token\n\n### PUT /change-email\n\n**Change user email address**\n\nRequest Auth:\n```\nAuthorization: Bearer <jwt_token>\nContent-Type: application/json\n```\n\nRequest body:\n```json\n{\n  \"newEmail\": \"newemail@example.com\"\n}\n```\n\nResponse (200 OK):\n```json\n{\n  \"message\": \"Email updated successfully\",\n  \"user\": {\n    \"id\": 1,\n    \"email\": \"newemail@example.com\",\n    \"name\": \"John Doe\"\n  }\n}\n```\n\nValidation:\n- `newEmail`: valid email format, not already in use\n\nErrors:\n- `401 Unauthorized` - no token\n- `400 Bad Request` - invalid email format\n- `409 Conflict` - email already exists\n\n### PUT /change-password\n\n**Change user password**\n\nRequest Auth:\n```\nAuthorization: Bearer <jwt_token>\nContent-Type: application/json\n```\n\nRequest body:\n```json\n{\n  \"currentPassword\": \"oldPassword123\",\n  \"newPassword\": \"newPassword456\"\n}\n```\n\nResponse (200 OK):\n```json\n{\n  \"message\": \"Password changed successfully\"\n}\n```\n\nValidation:\n- `currentPassword`: must match current hash (bcrypt.compare)\n- `newPassword`: minimum 6 chars, different from current\n\nErrors:\n- `401 Unauthorized` - no token\n- `400 Bad Request` - invalid current password\n- `400 Bad Request` - new password too short\n- `400 Bad Request` - new password same as current\n\n### POST /gdpr/export\n\n**Request user data export (GDPR Article 15)**\n\nRequest Auth:\n```\nAuthorization: Bearer <jwt_token>\nContent-Type: application/json\n```\n\nRequest body: None (empty)\n\nResponse (202 Accepted):\n```json\n{\n  \"message\": \"Data export request submitted. Check email for download link.\",\n  \"request_id\": \"uuid-1234\"\n}\n```\n\nBackend:\n- Creates entry in `gdpr_delete_requests` (type='export')\n- Sends email with token link\n- Link valid for 24 hours\n- Download contains:\n  - user_auth (id, email, name, created_at)\n  - user_profiles (name, avatar, wallet_address)\n  - transactions (all transfers, dates, amounts)\n\nErrors:\n- `401 Unauthorized` - no token\n\n### POST /gdpr/delete-request\n\n**Request account deletion (GDPR Article 17)**\n\nRequest Auth:\n```\nAuthorization: Bearer <jwt_token>\nContent-Type: application/json\n```\n\nRequest body:\n```json\n{\n  \"reason\": \"optional string\"\n}\n```\n\nResponse (202 Accepted):\n```json\n{\n  \"message\": \"Deletion request submitted. Confirm via email.\",\n  \"request_id\": \"uuid-5678\"\n}\n```\n\nBackend:\n- Creates entry in `gdpr_delete_requests` (type='delete')\n- Sends confirmation email with token\n- User must click link to confirm within 24 hours\n- On confirmation: deletes user_auth + user_profiles + related data\n\nErrors:\n- `401 Unauthorized` - no token\n\n### GET /metrics\n\n**Prometheus metrics endpoint**\n\nRequest: None\n\nResponse (200 OK): Prometheus text format\n```\n# HELP auth_login_total Total login attempts\n# TYPE auth_login_total counter\nauth_login_total{result=\"success\"} 150\nauth_login_total{result=\"failed\"} 23\n\n# HELP auth_2fa_total Total 2FA events\n# TYPE auth_2fa_total counter\nauth_2fa_total{action=\"setup\"} 15\nauth_2fa_total{action=\"verify\"} 14\nauth_2fa_total{action=\"disable\"} 1\nauth_2fa_total{action=\"authenticate\"} 142\nauth_2fa_total{action=\"authenticate\",result=\"failed\"} 3\n\n# HELP db_query_duration_seconds Database query latency\n# TYPE db_query_duration_seconds histogram\ndb_query_duration_seconds_bucket{le=\"0.1\",operation=\"getUserById\"} 1450\n```\n\nIntended for Prometheus scraper (scraped every 15s).\n\nErrors: None (always succeeds)\n\n## Error Response Format\n\nAll errors return consistent JSON:\n\n```json\n{\n  \"error\": \"Descriptive message\",\n  \"code\": \"ERROR_CODE\",\n  \"details\": {}\n}\n```\n\nExample 401:\n```json\n{\n  \"error\": \"Invalid or expired token\",\n  \"code\": \"AUTH_INVALID_TOKEN\"\n}\n```\n\nExample 409 (email conflict):\n```json\n{\n  \"error\": \"Email already exists\",\n  \"code\": \"AUTH_EMAIL_TAKEN\",\n  \"details\": { \"email\": \"john@example.com\" }\n}\n```\n\n## JWT Token Structure\n\nSTandard JWT (HS256):\n\nHeader:\n```json\n{\n  \"alg\": \"HS256\",\n  \"typ\": \"JWT\"\n}\n```\n\nPayload:\n```json\n{\n  \"id\": 1,\n  \"email\": \"john@example.com\",\n  \"iat\": 1710568200,\n  \"exp\": 1710654600\n}\n```\n\nWith pending 2FA:\n```json\n{\n  \"id\": 1,\n  \"email\": \"john@example.com\",\n  \"twoFactorPending\": true,\n  \"iat\": 1710568200,\n  \"exp\": 1710568500  // 5 min\n}\n```\n\nUsage:\n```\nAuthorization: Bearer <full_jwt>\n```\n\n## Rate Limiting\n\nAll endpoints subject to NGINX rate limiting:\n\n| Endpoint | Limit | Window |\n|----------|-------|--------|\n| `POST /login` | 10 req | 1 min |\n| `POST /register` | 3 req | 1 min |\n| Other auth routes | 20 req | 1 min |\n\nExceeding limit returns `HTTP 429 Too Many Requests`.\n\n## Authentication Flow Summary\n\n1. User provides email + password\n2. Server validates credentials\n3. If 2FA enabled:\n   - Return tempToken (5m) + `requires2FA: true`\n   - User verifies TOTP code\n   - Exchange tempToken + code for full JWT\n4. If 2FA disabled:\n   - Return full JWT immediately (24h)\n5. Client stores JWT in sessionStorage\n6. All subsequent requests include JWT in header"}
